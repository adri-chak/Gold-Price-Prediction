# Gold Price Prediction

A machine learning project that predicts daily gold prices using historical financial data and a Random Forest Regressor.

## Project Overview
This project uses historical data of various financial assets—such as stock indices, currency exchange rates, and precious metals—to train a Random Forest model that accurately forecasts the price of gold.

## Repository Structure
* `Gold Price Prediction.ipynb` : Jupyter notebook containing data analysis, cleaning, and modeling.
* `gld_price_data.csv` : Dataset containing historical daily prices.
* `README.md` : Project documentation.
* `\images` : Project visualizations and graphs.

## Core Features
* Data cleaning and normalization.
* Correlation analysis between financial indicators.
* Model training using Random Forest Regressor.
* Performance evaluation using R-squared ($R^2$) score.

## Technologies Used
* Python
* Pandas & NumPy (Data Manipulation)
* Scikit-Learn (Machine Learning)
* Matplotlib & Seaborn (Data Visualization)
